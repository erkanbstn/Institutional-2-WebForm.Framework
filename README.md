# Kurumsal site

Kurumsal tanıtım sayfaları olan web formu.

## Ne var

Sayfalar `ZesuSite` projesindedir.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework, Web Forms ve Entity Framework.
